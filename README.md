# 加藤惠 Codex 桌宠 · 惠惠

Windows x64 桌面陪伴应用，使用 .NET 10 / WPF。下载 Releases 中的便携 ZIP，完整解压后运行 HuiHuiPet.exe，无需额外安装 .NET。

## 功能

- 透明置顶桌宠，拖动、缩放、随机动作和整屏散步。
- 自动趴在窗口上沿并跟随窗口移动；从屏幕左右边缘侧身探头。
- 趴窗、探头采用动态随机节奏，分别支持开关和频率调节。
- 133 条本地中文台词，按动作选择、避免连续重复，支持关闭轻微吐槽。
- Codex 工作状态和公开进度气泡，双击回到 Codex；悬浮追问继续原会话。
- 系统托盘、专注计时、提醒和全屏自动隐藏。

## Codex 联动

普通宠物功能无需 Codex。自动跟随需要本机 Codex 会话记录；默认检测当前用户的 .codex/sessions 或 CODEX_HOME。发送追问另需已登录、支持 queue 的 Codex CLI。联动依赖本地记录格式及 CLI 版本，可能需要后续适配。

不含发布者的账号、登录凭据或个人会话。台词本地选择，不调用模型。任务使用对方自己的 Codex 账号；审批及完整结果在 Codex 中查看。

## 使用

1. 下载最新版 Windows x64 便携 ZIP 并完整解压。
2. 升级时先从托盘退出旧版，再运行新版 HuiHuiPet.exe。
3. 右键宠物或托盘进入设置。角色台词在 Assets/dialogue.zh-CN.json，可编辑后重启生效。

自动趴窗与探头每次随机停留 8–25 秒；当前没有停留时长设置。节奏基准控制触发机会，不是固定周期。手动趴窗不会自动超时。
